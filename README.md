# Mayank R. - Portfolio

A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS. Showcasing my projects, skills, and experience as a web developer.

![Portfolio Preview](/public/avatar.jpeg)

## 🚀 Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) - React framework with App Router
- **Language:** [TypeScript](https://www.typescriptlang.org/) - Type-safe JavaScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/) - Re-usable components
- **Animations:** [Framer Motion](https://www.framer.com/motion/) - React animation library
- **Icons:** [Lucide React](https://lucide.dev/) - Beautiful icons
- **Package Manager:** Bun/Yarn

## ✨ Features

- **Responsive Design** - Fully responsive layout that works on all devices
- **Dark/Light Mode** - Theme toggle with next-themes
- **Smooth Animations** - Blur fade effects and transitions using Framer Motion
- **Project Showcase** - Display of featured projects with live demos and source code
- **Contact Form** - Functional contact page for reaching out
- **Modern UI** - Clean and professional design with shadcn/ui components

## 🏃 Getting Started

### Prerequisites

- Node.js 18+ or Bun
- Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Mayank-Radadiya/portfolio.git
cd portfolio
```

2. Install dependencies:

```bash
bun install
# or
yarn install
```

3. Run the development server:

```bash
bun run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
bun run build
# or
yarn build
```

## 📁 Project Structure

```
portfolio/
├── src/
│   ├── app/              # Next.js app router pages
│   ├── components/       # React components
│   │   ├── magicui/     # Animation components
│   │   └── ui/          # shadcn/ui components
│   ├── data/            # Data files (resume, projects)
│   └── lib/             # Utility functions
├── public/              # Static assets
├── tailwind.config.ts   # Tailwind configuration
└── next.config.mjs      # Next.js configuration
```

## 🎨 Customization

To personalize this portfolio:

1. Update personal information in [`src/data/resume.tsx`](src/data/resume.tsx)
2. Replace avatar image in [`public/avatar.jpeg`](public/avatar.jpeg)
3. Add your own projects to the projects array
4. Modify theme colors in [`tailwind.config.ts`](tailwind.config.ts)
